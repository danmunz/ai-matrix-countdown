Five trends are already underway in 2026. Each is separately reasonable — a cheaper way to buy compute, a fairer way to own it, a medical breakthrough, a better interface, a manager that never sleeps. None of them is a conspiracy. None of them requires a machine that hates you.
The story is what happens when they interlock: compute becomes a household commodity, then an asset class, then a biological one, then the place people live, and finally something no person is left administering. Follow any one and it looks like progress. Follow all five and it looks like August 7 2068.

Build notes — live site
Canvas + breakpoints
Design canvas 1400px. Live: fluid content column, max-width 1400, min 1120 before reflow. Breakpoints: ≥1024 desktop (48px gutters); 640–1023 seeds row wraps 2+3, entry-detail sidebar folds below body; ≤639 per screen 09 (16px gutters, scrubber docks fixed to bottom edge). Timeline table never horizontally scrolls — columns compress, glyph dots collapse to a count.
Spacing scale
4px base: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64. Section rhythm 40–64. Hairlines 1px rgba(11,11,11,0.12); structural rules 2.5px solid #0B0B0B; band separations always rule + gap, never gap alone.
Countdown math
Target 2068-08-07T00:00:00Z. days remaining = ceil((target − now) / 86400000), computed in UTC. Recompute on a timer scheduled to the next UTC midnight AND on visibilitychange (tab wake). Odometer rolls per digit column: translateY, 1.4s cubic-bezier(.2,.85,.25,1), 70ms stagger left→right. Numeric readout wrapped in aria-live="polite" — announce once per day change, never per animation frame.
Font loading
Five families, exact weights only: Geist 700/800 · Atkinson Hyperlegible Mono 400/700 · Major Mono Display 400 · Oswald 600/700 · Archivo Black 400. font-display:swap; preload woff2 for Geist 700 + AHM 400 (above the fold). Fallbacks: system-ui / ui-monospace / monospace / Arial Narrow / Arial Black. Day numbers in AHM get font-variant-numeric: tabular-nums; Major Mono is inherently monospaced — never letter-space it.
Layer model
z-0 fresco plate (mix-blend-mode:multiply, pointer-events:none) · z-1 content · z-5 chrome bars (translucent paper #EDF1F2 at 0.9+) · z-10 sticky scrubber · z-100 CHANNELS overlay. Overlay traps focus, locks body scroll, closes on ESC and ×. Nothing else ever exceeds z-10.
Routes + state
/ · /timeline (read|map toggle in query) · /day/:n (negative integer, e.g. /day/-14500) · /seeds · /seed/:slug (komputilo | laboro | cerbo | songo | autoritato) · /about. Core state: { daysLeft, view, idx, committed, frac|null, menuPhase }. Deep links restore scrubber position from the URL; browser back returns to the previous day.
Scrubber contract
Drag is RELATIVE — the handle moves from where it is by pointer delta; clicking the track never jumps. Pointer capture on pointerdown; live day/date readout every frame; nearest-entry magnet during drag; COMMIT ON RELEASE ONLY → navigate to /day/:n. Tick spacing is nonlinear: x(i) = 2 + (i/47)^1.15 × 96 (%). Handle visual 28px, hit target ≥44px.
Assets
8 fresco halftone PNGs (~1400w) — serve AVIF/WebP with PNG fallback, lazy-load below the fold, preload only the landing plate. 5 seed icons: square 1:1 PNGs served at 2× render size (rendered 100px desktop / 52px mobile lists). Grain textures are runtime canvas — full redraw every 90ms, alpha 55–80; no image asset.
Accessibility
prefers-reduced-motion: kill stripe drift, marquee, grain redraw and scramble decode (render settled text instantly); odometer becomes an instant swap. Focus visible: 2px #B31E2C outline, offset 2. Touch targets ≥44px even where marks are smaller. Faint mono micro-labels (9.5px / 0.3 alpha) are decorative — their meaning must also exist in accessible text. #B31E2C on black fails AA below 24px: on dark chrome pair it with adjacent paper-white text or lift to #E8556A.
Performance
The page is animation-heavy — budget it. Pause every infinite loop (stripes, marquee, grain, eq bars, blink) when its section leaves the viewport (IntersectionObserver); cap concurrent loops. Animate only transform / background-position / opacity. Multiply-blend zones stay confined to hero regions. LCP is the odometer — pure text, no image dependency; render it server-side with the correct day count.
